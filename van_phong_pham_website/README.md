# Dự án Website Cửa hàng Văn phòng phẩm

Hệ thống quản lý bán hàng văn phòng phẩm trực tuyến. **Lưu ý:** Dữ liệu cấu hình hệ thống được lưu *biệt lập* để bảo mật.

## Cấu trúc thư mục

| Thư mục | Nội dung |
| :--- | :--- |
| `data/` | Lưu trữ file Excel đơn bán hàng |
| `docs/` | Tài liệu nhập hàng và quy trình |
| `logs/` | File log ghi nhật ký vận hành hệ thống |

## Lệnh hệ thống
```powershell
Get-ChildItem -Force
```

## Tiến độ công việc
- [x] Sắp xếp và chuẩn hóa cấu trúc cây thư mục
- [ ] Thiết lập công thức tính toán đơn bán tháng 10
